# 🎬 MovieHub

MovieHub is a modern movie browsing application built with React.  
Users can explore movies, search for their favorite movies, view movie details, and save movies to favorites.

## 🚀 Features

- 🔍 Search for movies
- 🎥 Browse popular movies
- 📄 View detailed information about each movie
- ❤️ Add and remove movies from favorites
- ⚡ Fast and responsive user interface
- 🌙 Dark theme design

## 🛠️ Technologies Used

- React.js
- Vite
- React Router DOM
- JavaScript (ES6+)
- CSS / Tailwind CSS
- API Integration
- Git & GitHub
